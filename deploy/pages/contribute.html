Find your lane

More than just code.

Our current open-source product is Cellar Guard, a Java-based CSV compatibility checker. These are practical ways to help it improve.

01 / Engineering

Build & fix.

Improve Java checks, the browser experience, developer workflows and clear error reporting. Include tests when behavior changes.

See issues
02 / Quality

Test the edges.

Try CSV examples, unusual headers, mobile interactions and keyboard navigation. Report exactly what happened and how to reproduce it.

Report an issue
03 / Documentation

Make it clear.

Improve setup steps, examples, manuals, accessibility explanations and translations so new users know what to do next.

Read the guide
04 / Design & feedback

Shape the experience.

Suggest clearer interfaces, usability improvements and honest product messaging. Open an issue before starting a major redesign.

Your first contribution

Start small.
Ship something useful.

No special contributor account or invitation is needed to suggest a public issue or open a pull request. Maintainers review changes before merging.

Step 01 / Choose

Pick one issue.

Browse open issues. If you're unsure, comment with your proposed approach before you begin.

Browse issues
Step 02 / Build

Work on a branch.

Fork or clone the repository, create a focused branch, and run java Build.java test with Java 21+.

Contribution rules
Step 03 / Share

Open a pull request.

Explain the change, show test results, and use synthetic CSV data. Never include private exports, credentials or customer information.

View pull requests

Not ready to code? A clear bug report, reproducible CSV example using invented data, or documentation correction is a valuable contribution too. Read the security policy before reporting sensitive vulnerabilities.
