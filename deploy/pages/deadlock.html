Deadlock Sentinel.

Two threads can freeze when each waits for a lock owned by the other. Sentinel analyzes JVM thread-dump snapshots, traces wait-for relationships and reports the cycle with evidence.

Detection pipeline

Evidence before confidence.

01 / PARSE

Read the snapshot

Extract JVM thread IDs, held locks, ownable synchronizers and awaited locks.

02 / GRAPH

Resolve owners

Connect each waiting thread to the owner of the lock it needs.

03 / DETECT

Identify cycles

Follow relationships until a cycle is proven or the chain ends.

Developer quick start

Run the Java analyzer.

From a local checkout of the Cellar Studio repository, compile the dependency-free Java source and run a synthetic example:

cd products/deadlock-sentinel
javac -d out src/main/java/com/cellar/deadlock/DeadlockSentinel.java
java -cp out com.cellar.deadlock.DeadlockSentinel --demo

Exit 1 = cycle detected, 0 = no cycle found in this snapshot, 2 = invalid input. No detected cycle does not prove a process will never deadlock.
