How the check works

One export can feed several customer workflows.

Define a contract

Declare the columns, types, and values each import expects. Give every contract an owner.

Check the export

Read the CSV against each contract. See which workflows passed and what the failing workflow needs.

Gate the release

Block CI when a required integration breaks. Fix the export and rerun the same check.
