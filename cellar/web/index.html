Everything here also works from the command line.

Run in CI: cellar check --csv build/sales_export.csv --summary

Machine-readable: cellar check --csv export.csv --format json

Exit codes: 0 all pass  1 a contract failed  2 invalid input

A pass means the header meets the declared requirements. Value formats, units and data rows are not checked. Only the header leaves your file; this page runs on your computer.
