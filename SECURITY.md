# Security

Cellar Web is a pilot-stage web application. Read `docs/WEB_SECURITY.md` for the threat model, the controls, and, importantly, what is **not** protected. No independent audit or penetration test has been performed.

If you find a vulnerability, do not put customer data, secrets or working exploits in a public issue. Use the repository's private vulnerability reporting if enabled, or arrange a private channel with the maintainer. This repository does not guarantee a response time.

Use synthetic reproduction files. Include version, Java/OS version, expected versus actual behaviour and minimal steps.
