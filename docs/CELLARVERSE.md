# Renamed: Cellar Studio

**Cellar Studio** is the official primary name for the multiproduct company platform. The old name, Cellarverse, is retired.

Please use the current [Cellar Studio platform and product roadmap](CELLAR_STUDIO.md).

This compatibility page remains only so previously shared GitHub links continue working. The existing Cellar Guard repository, URLs and individual product source repositories are not being renamed.
